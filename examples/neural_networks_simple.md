# Neural Networks

Neural networks are computational models inspired by the human brain.

## Basic Neuron

A neuron receives inputs and produces an output:

$y = f(wx + b)$

Where $w$ is weight and $b$ is bias.

## Common Functions

- Sigmoid: $f(x) = 1/(1+e^{-x})$
- ReLU: $f(x) = max(0,x)$
- Tanh: $f(x) = tanh(x)$

## Learning Process

Networks learn by adjusting weights to minimize loss.

## Applications

- Image recognition
- Natural language processing
- Speech recognition
- Recommendation systems

Neural networks power modern AI!
